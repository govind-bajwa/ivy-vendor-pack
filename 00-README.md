## File conventions

- `.md` files: Markdown. Renders cleanly in GitHub, VS Code, Cursor, or any editor.
- `.html` files: static, no build step. Open in any modern browser.
- All screenshots in [`04-user-flows/`](04-user-flows/) resolve to [`05-wireframes/screenshots/`](05-wireframes/screenshots/) or [`06-hifi-mockups/screenshots/`](06-hifi-mockups/screenshots/).
- [`07-design-system/ivy-tokens.css`](07-design-system/ivy-tokens.css) is the canonical source of every colour, typeface, and spacing token.

## When to open which doc

- **Need to know what a feature does?** → [`01-prd.md`](01-prd.md)
- **Need to know how a stage feels in use?** → [`02-user-workflow-9-stages.md`](02-user-workflow-9-stages.md)
- **Need to know why a feature is the priority it is?** → [`03-feature-priority-matrix.md`](03-feature-priority-matrix.md)
- **Need to know what comes after the current build?** → [`04-roadmap.md`](04-roadmap.md)

> **Note on terminology.** These source documents use internal version labels (v1.0, v1.1 etc.) and short feature codes (F1, A2, C4 etc.). These are working labels for us — you don't need to memorise them. The features themselves are described in plain English alongside each code.
